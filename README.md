# Пояснительный файл

Записка к файлам лабораторных работы по дисциплине программная инженерия; Подготовил Сивков Владислав из группы КС-26

## Общее описание

Большинство файлов имеет несколько страниц для разных вариантов задания: с установкой python и с программой.

## Состояние лабораторных
- [x] Лабораторная 1
  - Запишите свое ФИО в таблицу группы
  - создайте облачную папку (индивидуальную или в облачной папке группы, ссылку разместите в ячейке напротив вашей фамилии) 
  - Создайте ДВИ вашей работы на первой лабораторной работе по предмету Программирование (преподаватель Васецкий)

    - если введен 0 вывыодится сообщение об этом.

## Описание содержимого первой ветви (main)

### Диаграмма вариантов использования

[ДВИ1](ДВИ1.drawio) представляет собой первую версию файла диаграммы, в последствии была изменена до
версии [ДВИ2](ДВИ2.drawio), в которой были совершены некоторые изменения.

### Диаграмма деятельности

[Диаграмма](Диаграмма%20деятельности1.drawio) описывает логику и последовательность выполнения действий.

### Диаграмма компонентов

[Диаграмма](Диаграмма%20компонентов1.drawio) описывает основные составные части проекта, без которых
выполнение программы не представляется возможным.

### Диаграмма развертывания

[Диаграмма](Диаграмма%20развертывания1.drawio) описывает, связь компонентов программы и устройства, на котором этот
компонент запущен

### Диаграмма последовательности

Данная диаграмма, как и ДВИ представлена в двух экземплярах [первый](Диаграмма_последовательности.drawio)
и [второй](Диаграмма_последовательности2.drawio), аналогично ДВИ, второй файл просто содержит правки, относительно
первого. Данная диаграмма позволяет определить последовательность и устройство обращений внутри проекта, она связывает
отдельные компоненты устройства с их функциями и показывает, куда может исходить запрос этой функции, чего ожидает
программа, какие побочные компоненты образуются и срок их жизни.
