ПОЯСНИТЕЛЬНЫЙ ФАЙЛ

Репозиторий содержит материалы лабораторных работ по дисциплине
«Программная инженерия». В нём размещены UML-диаграммы, описывающие
работу учебной программы, а также отдельная ветка с решением задачи на
языке Prolog.

РЕПОЗИТОРИЙ

Ссылка: https://github.com/VenalusDev/PE

ОПИСАНИЕ ВЕТОК

main Основная ветка с материалами первых лабораторных работ. В ней
находятся диаграммы, описывающие поведение программы, взаимодействие её
частей и структуру проекта.

prolog Ветка с решением логической задачи на языке Prolog. В задаче
рассматривается распределение тематик коллекционирования марок между
Серым Волком, Ниф-Нифом, Наф-Нафом и Нуф-Нуфом с учётом заданных условий
об их расположении за столом.

third Дополнительная ветка репозитория.

СОДЕРЖИМОЕ ВЕТКИ main

ДВИ1.drawio Первая версия диаграммы вариантов использования.

ДВИ2.drawio Обновлённая версия диаграммы вариантов использования с
внесёнными изменениями.

Диаграмма деятельности1.drawio Диаграмма деятельности, показывающая
последовательность действий и логику выполнения основного сценария
программы.

Диаграмма компонентов1.drawio Диаграмма компонентов, отображающая
основные составные части проекта и их назначение.

Диаграмма развертывания1.drawio Диаграмма развертывания, показывающая
размещение компонентов программы на устройствах и связь программных
частей с используемой средой.

Диаграмма_последовательности.drawio Первая версия диаграммы
последовательности. Отражает порядок обмена сообщениями между
участниками и компонентами программы.

Диаграмма_последовательности2.drawio Обновлённая версия диаграммы
последовательности с исправлениями относительно первой версии.

ФОРМАТ ФАЙЛОВ

Файлы с расширением .drawio являются диаграммами, созданными в редакторе
diagrams.net (draw.io). Их можно открыть в самом редакторе для просмотра
и редактирования.

НАЗНАЧЕНИЕ РЕПОЗИТОРИЯ

Репозиторий используется для хранения и систематизации результатов
лабораторных работ. Разделение материалов по веткам позволяет отдельно
хранить UML-диаграммы и программу на Prolog.
